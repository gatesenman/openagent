# OpenAgent

AI-driven full lifecycle software development platform.

## What's new

`openagent new-project <dir>` writes a verifiable starter tree: `openagent.project.json`, a `requirements.txt` stub, and a passing placeholder test. No remote API is required.

```bash
python3 cli/openagent_cli.py new-project ./demo-app
python -m unittest discover -s cli/tests
```

## Overview
OpenAgent is an AI-powered platform covering the complete software development lifecycle — from requirements to code generation, testing, and deployment.
